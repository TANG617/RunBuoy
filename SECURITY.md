# Security policy

## Reporting

Do not open a public issue for a suspected vulnerability. Use GitHub's
**Report a vulnerability** private security advisory flow for this repository
and include affected commit, configuration, reproduction, impact, and any
known mitigation. Do not include live credentials or personal data.

## Supported version

Security fixes target the latest default branch and active release. This MVP
has no promise of support for the removed rzr terminal implementation.

## Permanent boundary

RunBuoy is read-only from iPhone to Machine. A Server or mobile feature that
can execute, cancel, retry, signal, approve, attach, type, or send input to a
Machine is a security defect even if access-controlled.
