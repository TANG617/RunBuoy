## 三步开始

<div className="runbuoy-flow">
  <div>
    <strong>1. 安装 CLI</strong>
    <span>使用 uv 或 pipx 安装隔离的 Python 命令行工具。</span>
  </div>
  <div>
    <strong>2. 配对 iPhone</strong>
    <span>运行 runbuoy pair，用 iPhone 扫描五分钟有效的一次性配对码。</span>
  </div>
  <div>
    <strong>3. 启动任务</strong>
    <span>在原命令前加上 runbuoy run --，然后放心离开电脑。</span>
  </div>
</div>

```bash
uv tool install runbuoy
runbuoy doctor
runbuoy pair
runbuoy run -- python3 experiment.py
```

[查看完整安装与使用指南 →](/guide/)

## 一条不可跨越的边界

```text
Machine  →  RunBuoy Server  →  iPhone
```

RunBuoy 不是远程终端、SSH 客户端、手机 tmux，也不是 Agent 审批工具。

手机端没有开始、取消、重试、输入、信号、批准或回复入口。
