# RunBuoy support

RunBuoy does not publish a support email address. Use the channels below so your request reaches the right place without exposing secrets.

## Product help and bug reports

Open a [GitHub issue](https://github.com/TANG617/RunBuoy/issues) for setup questions, reproducible bugs, accessibility problems, and feature requests. Before posting:

1. Run `runbuoy doctor --json` and remove tokens, hostnames, paths, command arguments, and other sensitive values.
2. Include the RunBuoy CLI, server, and iOS versions you are using.
3. Describe whether you use the Global service or a self-hosted server, plus the smallest set of steps that reproduces the problem.

Never attach credentials, pairing codes, full logs, environment variables, or proprietary source code to a public issue.

## Security reports

Do not file a public issue for a suspected vulnerability. Follow the [security policy](https://github.com/TANG617/RunBuoy/security/policy) and use [GitHub private vulnerability reporting](https://github.com/TANG617/RunBuoy/security/advisories/new).

## Service and self-hosting

See [Service status](/en/status) for the meaning of the Global service health endpoints. Self-hosted operators own their availability, backups, retention configuration, and incident response; start with the [self-hosting guide](/en/self-hosting).

For privacy choices and deletion behavior, see the [privacy policy](/en/privacy).
