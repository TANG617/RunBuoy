## Start in three steps

<div className="runbuoy-flow">
  <div>
    <strong>1. Install the CLI</strong>
    <span>Use uv or pipx to install the standalone command-line tool.</span>
  </div>
  <div>
    <strong>2. Pair your iPhone</strong>
    <span>Scan a single-use pairing code and connect in seconds.</span>
  </div>
  <div>
    <strong>3. Start a run</strong>
    <span>Add runbuoy run -- to your command and keep up from anywhere.</span>
  </div>
</div>

```bash
uv tool install runbuoy
runbuoy completion install zsh
runbuoy doctor
runbuoy device pair
runbuoy demo live-activity
runbuoy run -- python3 experiment.py
```

[Read the complete setup and usage guide →](/docs/)

## Focused on status, never in the way

```text
Machine  →  RunBuoy Server  →  iPhone
```

Your task remains under the control of your computer while RunBuoy presents its progress and result on iPhone. Commands, source, environment variables, and full logs stay local by default. [Learn about privacy and data boundaries →](/privacy)
