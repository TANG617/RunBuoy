# iOS app

The RunBuoy iOS app requires **iOS 26 or later**. Its App Store release is being prepared and is not yet available for public download or pre-order.

This page will link to Apple’s official download or pre-order page when it becomes available. For now, you can:

- [Browse the source on GitHub](https://github.com/TANG617/RunBuoy)
- [Install the RunBuoy CLI](/en/guide/install)
- [Explore the native iOS client](https://github.com/TANG617/RunBuoy/tree/main/apps/ios)

:::info
The RunBuoy CLI is available on PyPI. The iOS App Store listing is not yet public, and the current end-to-end flow supports the `Global` region only.
:::
