## 三步开始使用

<div className="runbuoy-flow">
  <div>
    <strong>1. 安装 CLI</strong>
    <span>使用 uv 或 pipx 安装独立的命令行工具。</span>
  </div>
  <div>
    <strong>2. 配对 iPhone</strong>
    <span>扫描一次性配对码，在几秒内建立安全连接。</span>
  </div>
  <div>
    <strong>3. 启动任务</strong>
    <span>在原命令前加上 runbuoy run --，离开电脑也能掌握进度。</span>
  </div>
</div>

```bash
uv tool install runbuoy
runbuoy completion install zsh
runbuoy doctor
runbuoy device pair
runbuoy demo live-activity
runbuoy run -- python3 experiment.py
```

[查看完整安装与使用指南 →](/docs/)

## 专注状态，不打断任务

```text
Machine  →  RunBuoy Server  →  iPhone
```

任务仍由电脑端掌控，RunBuoy 在 iPhone 上清晰呈现进度与结果。命令、源码、环境变量与完整日志默认留在本机；[了解隐私与数据边界 →](/privacy)
