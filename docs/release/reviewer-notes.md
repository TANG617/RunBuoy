## Suggested notes

RunBuoy lets a user observe a long-running command from an iPhone. A machine
running the open-source RunBuoy CLI sends a safe title, structured progress,
status, and optional safe message to the RunBuoy Server. The iPhone can read
that state and receive notifications and Live Activities. It cannot start,
cancel, retry, approve, send terminal input, or otherwise control the machine.

Minimum OS: iOS 18.0.

No account username or password is required. The app creates a device identity
during onboarding and pairs to a machine with a short-lived, single-use QR
challenge generated by the CLI.

Review setup on a Mac or Linux computer with Python 3.12+ and `uv`:

1. Install the exact public CLI version for this submission:
   `uv tool install runbuoy==[CLI_VERSION]`.
2. Run `runbuoy doctor`, then `runbuoy device pair`.
3. On the review iPhone, select Global, allow or decline notifications, and scan
   the displayed QR code. The code expires after five minutes, so generate it
   during review rather than storing it in these notes.
4. Run `runbuoy demo live-activity` to exercise the real delivery path, or run
   `runbuoy run --title "App Review Demo" -- python -c "import time; time.sleep(30)"`
   to observe an active Run reach a terminal state.
5. Open the Run in the app and inspect its timeline and progress. Long-press the
   Dynamic Island or lock the phone to inspect the Live Activity on supported
   hardware.

Camera access is used only to decode the pairing QR code on-device. Camera
frames are not retained or uploaded. Notification permission is used for Run
changes; Live Activity tokens are used for ActivityKit delivery. The app works
without camera access when opened through a valid `runbuoy://pair` deep link,
and notification denial is handled in-app.

The Settings support link is `https://www.runbuoy.cloud/support`; the privacy
policy is `https://www.runbuoy.cloud/privacy`. Security reports use GitHub
private vulnerability reporting. RunBuoy has no verified public support email
in the source repository; the verified App Review contact fields are configured
privately in App Store Connect.
